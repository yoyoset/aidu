# AIDU v4.15.7 - First Official Release (首个正式版本发布) 🚀

Welcome to the debut of **AIDU** (Adaptive Immersive Deep English) – your mission-critical assistant for deep language acquisition.

## 🇬🇧 English Release Notes

### 🌟 Project Vision

AIDU is not just a translator; it is a **Full-Lifecycle Reading Tutor**. Built for professional learners and students, it bridges the gap between passive content consumption and active knowledge retention through AI-driven context mastery.

### 🚀 Key Pillars

1. **Intelligent AIDE Analysis**: Dynamic teaching personas (Humorous, Academic, Simple) and automated phrasal verb detection.
2. **Context-First Vocabulary**: Word capture linked to original reading sentences, powered by the **FSRS** spaced repetition algorithm.
3. **Ironclad Privacy**: Local-first architecture with optional secure cloud sync via GitHub Gist or Cloudflare Workers.
4. **Reader UI Excellence**: Fully customizable typography (font sizes, line spacing) and modern "Bubble" interaction model.

### 🛠️ Installation

Download the `dist.zip` from our [Releases](../../releases) and load it as an unpacked extension in Chrome Developer Mode.

## 🇨🇳 中文版发布说明

### 🌟 项目愿景

AIDU 不仅仅是一个翻译插件，它是一个**全生命周期的阅读导师**。专为深度学习者打造，通过 AI 技术将碎片化的网页阅读转化为结构化的知识积累。

### 🚀 核心亮点

1. **AIDE 智能分析引擎**: 多样化的教学风格（幽默风、小学老师、学术风）以及自动化的短语/熟词僻义捕捉。
2. **语境化词汇构建**: 生词与阅读原句深度关联记忆，内置最新的 **FSRS** 间隔复习算法。
3. **数据主权与隐私**: 本地化架构，支持通过 GitHub Gist 或 Cloudflare Workers 自定义加密同步。
4. **极致阅读体验**: 支持深度的字号、行间距自定义，以及现代化的“泡泡”交互模型。

### 🛠️ 快速安装

从 [Releases](../../releases) 页面下载 `dist.zip`，并在 Chrome 扩展程序页面开启“开发者模式”后，通过“加载已解压的扩展程序”导入。
