# AIDU 英语学习助手隐私政策

**生效日期：** 2026年2月11日

在 **方砖叔 (SquareUncle)**，我们非常重视您的隐私。本隐私政策说明了 **AIDU**（以下简称“本扩展”）如何处理您的信息。

## 1. 数据收集与使用

AIDU 遵循 **“本地优先 (Local-First)”** 的设计理念。

- **个人信息：** 本扩展不收集、不存储，也不会向我们的服务器传输任何个人身份信息 (PII)。
- **阅读数据：** 您选择分析或保存到文库的所有文本均存储在您浏览器的本地存储中。
- **词汇与进度：** 您的学习进度和单词本均存储在您的本地设备上。

## 2. 第三方 API 集成

为了提供智能分析，AIDU 允许您连接第三方大语言模型 (LLM) 提供商（如 Google Gemini, OpenAI 或 DeepSeek）。

- 当您请求分析时，必要的文本和上下文将直接发送到您配置的 API 提供商。
- 我们不会拦截或存储这些 API 调用。您与这些提供商的交互受其各自隐私政策的约束。

## 3. 存储与同步

- **本地存储：** 数据通过 Chrome 的 `storage.local` 和 `unlimitedStorage` API 进行保存。
- **可选云同步：** 如果您选择开启同步功能（通过 GitHub Gist 或 Cloudflare Workers），您的数据将被加密传输至您自己的私有存储空间。我们无法访问您的同步凭据或数据。

## 4. 权限使用说明

- `storage` & `unlimitedStorage`：用于在本地保存您的阅读列表和单词。
- `sidePanel`：用于提供沉浸式的阅读和学习界面。
- `activeTab` & `scripting`：用于允许您保存文章并与正在阅读的文本进行交互。
- `contextMenus`：用于提供“保存到 AIDU”右键菜单选项。
- `host_permissions` (<all_urls>)：必填项，以允许扩展在您选择阅读的任何教育网站或文章上运行。

## 5. 政策变更

我们可能会不时更新本隐私政策。任何变更都将通过页面顶部的“生效日期”反映。
